# ICK Technologies — Corporate Website

Emerging Africa-rooted technology company website. Corporate philosophy: **Integrated Technology & Human Progress**. This repository uses **TanStack Start / TanStack Router, React, TypeScript, Vite and Tailwind CSS**.

## Current status

- Sprint 01: frontend foundation.
- Sprint 02: Home and About content.
- Sprint 03: Services and Products consultation content.
- Sprint 04: **frontend-only, non-operational project inquiry preview** (`/discuss-project`). Verification pending; see `SPRINT-04.md`.
- Website remains **unpublished as last verified**; verify actual hosting state separately before making any deployment claims.

No inquiry submissions are accepted. No database, Supabase, authentication, email delivery, payments or production deployment is implemented by this work. The form is disabled, does not submit or persist data, and should not be used for confidential information. Google Fonts may still make third-party requests. ICK Opportunities is a separate product and must not be modified or integrated without approval.

## Development

Install dependencies using the project lockfile and run:

```sh
bun install --frozen-lockfile
bun run dev
bunx vitest run
bun run lint
bun run build
```

See `SPRINT-01.md` through `SPRINT-04.md` and `roadmap.md` for scope, tests, limitations and remaining approvals. No future sprint, backend enablement, or publishing is authorized by this repository update.
